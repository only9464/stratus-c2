# 05-02 · 页面与交互

> 每个页面回答三个问题：**它解决什么、关键交互是什么、失败时怎么提示**。
> 组件与主题见 [01-design-system](./01-design-system.md)。

---

## `/login`

- **解决**：拿到访问权。
- **交互**：输入 `ADMIN_TOKEN` → `GET /api/v1/me` 验证 → 存 `localStorage` → 跳 `?next`。
- **失败**：401 显示 `code + message`，**清空**已存的 token（避免"看起来登录了其实没登录"）。
- **Access 模式**：不显示输入框，直接点"进入"（`/me` 200 即通过）。

## `/`（概览）

- **解决**：5 秒内判断"现在有没有会话、任务顺不顺、额度还够不够"。
- **数据**：`GET /stats` + `GET /quota` + `GET /sessions?page_size=6`。
- **关键元素**：4 个数字卡（在线会话/任务总数/成功率/通道）；最近会话列表（点击进详情）；配额水位 6 条。
- **失败**：任一接口失败不阻塞整页，卡片显示 `—` 并在角落提示"部分数据不可用"。

## `/sessions`

- **解决**：找机器。
- **表格列**：主机（+ sid 缩写）、用户、系统、内网 IP、能力位、状态、最后心跳、操作。
- **交互**：搜索（host/user/ip/sid）、状态筛选、排序、分页、行点击进详情、`kill`（二次确认，展示影响原文）。
- **性能**：默认 20 行；`el-table` 在 > 200 行时启用虚拟滚动（v0.2）。

## `/sessions/:id`（会话详情）

这是**主战场**，四块：

1. **头部**：主机、状态、sid、OS/arch、用户、PID、内网/出口 IP、最后心跳。
2. **下发面板**：快捷任务（whoami / info / ps / id）+ 自定义 `shell.exec`。
   - 点击 → 浏览器**本地加密** → `POST /tasks` → 轮询结果 → 解密展示。
   - 没密钥时**不显示按钮**，改为"去生成密钥"的引导（避免"点了没反应"）。
3. **能力位 + 最近任务**：能力位驱动 UI（未上报的标签不渲染）。
4. **输出区**：时间 + 标题 + 等宽正文；`清空` 只清本地。

**失败提示**（必须区分）：

| 情况 | 文案 |
|---|---|
| 20 s 没结果 | "会话可能离线，或植入体未实现该任务类型" |
| `E_OFFLINE` | "会话离线，任务已入队，重连后自动补发" |
| 解密失败 | "结果解密失败：密钥不匹配或数据损坏"（不显示密文） |
| 结果已外置 R2 | "结果 > 4 KB 已存 R2，点击下载"（v0.2 前显示提示） |

## `/tasks`

- **解决**：全局任务流水与排查。
- **列**：任务 ID、会话、分类、状态、密文大小、下发/完成时间。
- **筛选**：状态、分类、会话。**注意**：看不到命令内容（服务端没有）。

## `/payloads`

- **解决**：生成身份 + 托管二进制 + 发一次性链接。
- **交互**：创建（名称/OS/arch）→ 弹出**仅显示一次**的 `psk` 与 `config` JSON（复制按钮）；
  上传二进制到 R2；生成 10 分钟一次性链接；吊销。
- **失败**：未登记操作员公钥时 409，提示"先去 /keys"。

## `/keys`

- **解决**：操作员身份（E2E 的另一半）。
- **交互**：生成 P-256（不可导出）→ 自动登记公钥 → 显示 `key_id` 与指纹；
  删除本地密钥（红色警告：历史结果将永久不可读）；吊销服务端登记。
- **提示**：指纹要能和队友口头核对（16 个十六进制字符）。

## `/audit`

- **解决**：复盘"谁在何时对哪个会话做了什么"。
- **列**：时间、角色、动作、目标、元数据（JSON 摘要）。
- **注意**：**不含命令明文**（服务端没有），也不含结果内容。

## `/quota`

- **解决**：知道"什么时候会撞线"。
- **内容**：9 项额度水位条（Workers/DO/D1/KV/R2）+ 口径说明 + 已记录的日用量。
- **阈值色**：> 80% 橙、> 95% 红；红色时在顶栏也显示一个角标（v0.2）。

## `/settings`

- **解决**：主题、令牌、安全边界的自我提醒。
- **内容**：暗色开关、`ADMIN_TOKEN` 更新、四条安全边界说明、"关于"。

## 全局交互约定

| 场景 | 约定 |
|---|---|
| 危险操作 | 二次确认弹层，展示服务端返回的 `impact` 原文；确认按钮为红色且文案具体（"标记 dead" 而不是 "确定"） |
| 加载 | 骨架屏 > 转圈；> 300 ms 才显示 |
| 空态 | 一句话 + 一个动作（"还没有会话 → 生成载荷"） |
| 错误 | 顶部 `el-message` + 页面内联说明（不要只弹 toast） |
| 键盘 | `Esc` 关弹层；表格行 `Enter` 打开；搜索框 `Enter` 提交 |
| 长文本 | 等宽 + `break-all`，超 4 KB 折叠 |
