# 02-05 · 威胁模型

> 目标：说清"防谁、不防谁、被破了会怎样"。**安全边界写清楚，比多写十行加密代码有用。**

---

## 1. 资产

| 资产 | 泄露后果 | 存放位置 |
|---|---|---|
| 任务明文（命令/参数） | 暴露演练意图、目标、手法 | 只在浏览器与植入体内存 |
| 结果明文（输出/文件内容） | 泄露目标数据 | 只在浏览器与植入体内存 |
| 操作员私钥 | 可解密该操作员的历史/未来任务 | 浏览器 IndexedDB（`CryptoKey`，不可导出） |
| 载荷 PSK | 可冒充该载荷注册新会话 | 植入体二进制里（构建时注入） |
| 会话令牌 | 可冒充某个已上线会话收发帧 | 植入体内存 |
| 元数据（主机名/内网 IP/时序/大小） | 暴露资产轮廓 | D1 / DO（服务端可见） |
| 审计日志 | 暴露"谁在何时做了什么" | D1 |

## 2. 对手与结论

### 2.1 被动网络观察者

能看到 TLS 外层、目标域名、包大小与时序。

| 能拿到 | 拿不到 |
|---|---|
| 你在和 `c2.example.com` 通信 | 命令内容、结果内容 |

**结论**：内容安全；**不做**流量整形（包大小/时序可被分析），这是明确的非目标。

### 2.2 Cloudflare（平台方）

能读 Worker 内存、DO/D1/R2 内容、日志，能看连接元数据。

| 能拿到 | 拿不到 |
|---|---|
| 全部密文、sid、序号、大小、时间、主机名（默认 `META_MODE=plain`） | L2 明文（没有操作员私钥） |

**结论**：零知识成立，但**元数据不隐藏**。要减少泄露就把 `META_MODE` 设 `sealed`
（代价：列表页在浏览器解密前显示 unknown）。

### 2.3 Cloudflare 账号被盗 / 内部人

能改 Worker 代码、读全部存储、删数据、注入任意帧、改配置。

| 能做 | 不能做 |
|---|---|
| DoS、删数据、观察元数据、伪造 L1 帧、**替换 `op_pub`**（会被植入体的指纹校验挡住） | 解密历史/未来任务；伪造合法的 L2 密文 |

**结论**：可用性归零，机密性保住。**这是本设计的核心收益**，也是为什么必须校验 `op_fp`。

### 2.4 拿到载荷样本的分析者

能逆向出 `endpoint`、`psk_id`、`psk`、`op_pub`、`op_fp`。

| 能做 | 不能做 |
|---|---|
| 用该 PSK 注册**新**会话（伪造主机上线） | 解密任何历史流量；伪造操作员任务 |
| 消耗你的 Workers 请求额度 | 影响已在线会话的密钥 |

**缓解**：载荷按"一次演练一个"生成；事后 `DELETE /api/v1/payloads/:id` 吊销；
控制台对"同一 psk_id 短时间内多 IP 注册"告警（`quarantined` 状态位已留）。

### 2.5 会话劫持者（拿到 sid，但没拿到 token）

| 能做 | 不能做 |
|---|---|
| 无（token 需要 `K_sess`，由 PSK 派生） | 冒充会话 |

### 2.6 恶意植入体（被诱导安装了伪造载荷）

- 它能向 edge 注册、能收到**它自己**的任务（因为操作员不会给它下发任务）。
- 它不能读其它会话的流量（DO 按 sid 隔离，token 绑定 sid+pub）。
- 它不能污染他人的结果（`res` 帧只写自己 sid 下的 task）。

### 2.7 操作员设备被攻破

- 攻击者拿到私钥 → 能解密该操作员能看到的所有任务与结果，能伪造任务。
- **这是身份的等价物，无法在协议层防**。缓解：设备隔离、密钥按演练轮换、`viewer` 角色不持有私钥。

## 3. 攻击面清单

| 面 | 暴露程度 | 现有控制 |
|---|---|---|
| `POST /v1/register` | 公网 | PSK-HMAC、时间窗 ±300s、nonce 去重、同 IP 5 次/分钟 |
| `GET /v1/ws/beacon` | 公网 | Bearer token（HMAC 校验）、seq 单调 |
| `POST /v1/beacon` | 公网 | 同上 + body ≤ 256 KB + 帧数 ≤ 32 |
| `PUT/GET /v1/file/:tid/:idx` | 公网 | token + `files.session_id == sid` 归属校验 + 片大小上限 |
| `GET /d/:token` | 公网 | 24B 随机令牌、10 分钟 TTL、一次性、未命中返回诱饵 404 |
| `ops.example.com/api/*` | 建议套 Access | token / Access header + 角色元数据 + 限流 |
| `ops.example.com/*`（SPA） | 同上 | 无敏感数据（全部内容在 API） |
| D1 / R2 / KV | 仅 Worker 可达 | 凭据在 CF 内部绑定，不出现在代码里 |

## 4. 我们不防的东西（写清楚，避免误判）

1. **流量分析**（大小/时序/连接模式）。
2. **平台侧元数据**（Cloudflare 知道谁在连哪个域名）。
3. **目标主机上的取证**（内存里的密钥、进程、网络连接）。
4. **供应链**（npm 依赖被投毒；用 lockfile + `pnpm audit`）。
5. **账号层封禁**（Cloudflare 因滥用条款封号；见 [prior art](../01-research/05-prior-art.md)）。
6. **操作员终端被控**（见 §2.7）。

## 5. 与 STRIDE 的对照（简表）

| 威胁 | 场景 | 缓解 |
|---|---|---|
| Spoofing | 伪造会话 / 伪造任务 | token HMAC；L2 AEAD；`op_fp` 校验 |
| Tampering | 改密文 / 改 seq / 改 sid | AEAD + AAD 绑定；seq 去重；sid 校验 |
| Repudiation | 操作员否认下发 | 审计日志（谁/何时/哪个会话/多大），**不含命令明文** |
| Information disclosure | 平台读内容 | 零知识 E2E |
| Denial of service | 刷注册 / 刷 beacon | 限速 + 体积上限 + 免费额度本身就是硬上限（会 1027） |
| Elevation | 越权访问别的会话 | DO 按 sid 隔离；console 角色元数据；`files` 归属校验 |
